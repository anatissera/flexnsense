   python -c "import torch; print(torch.cuda.is_available())"

3. Descarga el checkpoint (hace falta `hf auth login` con la cuenta JustoDario porque es privado):
   hf download JustoDario/flexnsense_act_skill1_rightindex2middle_63ep --local-dir ~/act63_ckpt

   cd robot_training/inference
   python make_camera_refs.py --src ~/data/flexnsense_skill1_raw --ref-views side,gripper,table

   python selftest.py --ticks 60 \

   Si falla, para y enséñame el error completo.
6. Comprueba Station: debe estar corriendo con el follower y las 3 cámaras, y el LEADER SIN TORQUE

   web de Station, puerto 8889).
